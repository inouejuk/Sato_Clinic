# 制作要件

- 添付のデスクトップ・スマホのトップページデザインを再現する。
- 写真・ロゴ・アイコン・背景は、支給された `assets.zip` の素材を使用する。
- HTML / CSS のみ。フレームワークとJavaScriptは使用しない。
- UTF-8、`lang="ja"`、Noto Sans JP。
- `header` / `main` / `section` / `article` / `footer` を使う。
- PC / タブレット / スマホの幅に対応する。
- 暗色の文字は `#2e3d37` を使用する。
- head に `<meta name="robots" content="noindex, nofollow">` を入れる。
- フッターには依頼された断り書きを全文掲載する。
- `directorySample.png` のディレクトリ構成を基本とする。
- ZIPで納品する。公開作業は今回の対象に含めない。

支給の制作依頼書と掲載原稿は同じフォルダーに保持しています。
実装対象は、依頼文と授業資料に示されたトップページと、追加依頼のお知らせ・診療内容・当院についての3ページです。下層ページも支給原稿・素材を使用し、トップページのトーンを踏襲します。
追加の画面修正指示により、上部メニューの項目追加・並び替え、トップページのアクセスとスタッフ紹介の並び替えを適用します。デスクトップではヒーロー写真に半透明の白い帯を重ね、帯とボタン群だけをスクロールに追従させます。ロゴはページと一緒にスクロールさせます。ヒーローは切り欠きのない角丸の長方形とします。900px以下のヘッダーは従来の追従表示を維持します。
