# 実装仕様

## セクション順

ヒーロー → 写真3枚 → お知らせ → ご挨拶 → 診療内容 → 当院について → スタッフ紹介 → アクセス・診療時間 → 診療科目 → フッター。

## レスポンシブ

- PC：写真と原稿を左右に配置。診療内容とスタッフ紹介は交互に左右を切り替える。
- 768〜1100px：余白とナビゲーションを調整する。
- 767px以下：写真と原稿を縦に並べる。カードの背景色を外す。お知らせの左写真、当院についての写真は添付スマホデザインに合わせて非表示。
- 374px以下：見出しと診療時間表の文字を調整する。

## HTMLのみの開閉

メニュー・お知らせ詳細・その他の診療内容・当院の詳しい紹介は `details` / `summary` で開閉する。
キーボードのEnter / Spaceでも操作可能。JavaScriptは不要。

## 地図・連絡先

地図は支給された `map.jpg` を使用する。クリックすると画像自体を新しいタブで開く。
医院・人物・連絡先・住所は架空。電話番号とメールは表示のみで、発信リンク・送信フォームは設けない。

## CSS

`css/style.css` から `assets/css/style.css` を読み込む。メインCSSを一箇所だけ管理する。
画像は `assets/images/` 配下。ファイル名・フォルダー名の大文字小文字を一致させる。
