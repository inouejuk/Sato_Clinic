# 実装仕様

## セクション順

ヒーロー → 写真3枚 → お知らせ（白地） → ご挨拶（緑地） → 診療内容（白地） → 当院について（緑地） → スタッフ紹介（白地） → アクセス・診療時間（緑地） → 診療科目（白地） → フッター。

## レスポンシブ

- PC：写真と原稿を左右に配置。診療内容とスタッフ紹介は交互に左右を切り替える。
- トップの診療内容4項目・スタッフ紹介4名は、PCで淡いグリーンの背景・写真・原稿を1枚のカードにまとめ、枠線と影を付ける。既存のフェードアップ処理をカード全体に適用し、動きの軽減設定ではカードを初めから表示する。
- 768〜1100px：余白とナビゲーションを調整する。900px以下は開閉式メニューを使う。
- 767px以下：写真と原稿を縦に並べる。診療内容のカードの背景色を外す。スタッフ紹介は写真・氏名・紹介文を淡いグリーンのカードにまとめる。お知らせの左写真、当院についての写真は添付スマホデザインに合わせて非表示。
- 374px以下：見出しと診療時間表の文字を調整する。
- 901px以上では画面幅いっぱいの白50％の帯をトップのヒーロー写真に重ね、帯と横並びのボタン群だけを画面上部に固定する。ロゴは白い角丸カードに載せ、帯より手前でページと一緒にスクロールさせる。下層ページも帯とボタンだけを固定し、本文はヘッダーの下に配置する。ボタンは緑地に白文字とする。900px以下のヘッダーと開閉メニューは従来の追従表示を維持する。ページ内リンクは追従帯・ヘッダーの高さに24pxを加えた余白を設ける。
- 901px以上のトップのヒーロー画像は、切り欠きのない角丸長方形とし、横幅と高さの比率は1.92:1とする。キャッチコピーは写真の左上で帯の下に置き、枠線を付けず半透明の白背景を添える。900px以下の写真サイズ・見出し配置は従来どおり。

## スマホのカルーセル

- 767px以下では、トップのヒーロー直下の写真3枚と、トップ・当院についてのスタッフ紹介4名を横スクロールで表示する。
- スマホでは写真のフェードアップを無効にする。写真を初めから不透明・移動なしで表示し、スワイプ中にもフェード用のトランジションを適用しない。
- スタッフの写真・氏名・紹介文を1つのスライドにまとめる。原稿を省略せず、縦スクロールで全文を読めるようにする。
- トップ・当院についてのスタッフ紹介は、各スライド全体に淡いグリーンの背景・枠線・24pxの角丸・控えめな影を付ける。写真をカード上部に収め、紹介文に左右20pxの余白を設ける。カードの高さを揃え、横スワイプと丸の位置表示を維持する。
- CSSの `scroll-snap` を使い、スワイプ後にスライドの先頭で止める。次のスライドの一部を見せ、下に写真3個・スタッフ4個の小さい丸のリンクを用意する。案内文と番号は表示しない。
- 表示中の丸は緑、それ以外は灰色にする。`scroll-target-group` と `:target-current` でスワイプ・リンク操作のどちらにも追従する。未対応の場合は、名前付き `scroll-timeline` と段階的な色のアニメーションで現在位置を示す。
- 丸には写真・スタッフ名の読み上げ用ラベルと28×44pxの操作領域を設け、見た目の丸は直径10pxにする。
- 位置の検出に使うCSSが両方とも未対応の場合は丸を非表示にする。横スワイプ・キーボードでの閲覧は維持する。対応ブラウザーの情報はREADMEの留意事項を参照する。
- スクロール領域はキーボードでも選択・操作できる。動きの軽減設定では滑らかなスクロールを無効にする。
- 768px以上では写真3列とスタッフの縦並びを維持し、丸のリンクは表示しない。ヒーロー直下・お知らせ・ご挨拶の写真と、トップの診療内容・スタッフ紹介のカード全体は、既存の `assets/js/script.js` による表示領域の検出とCSSでフェードアップする。
- カルーセル自体にはJavaScript、外部ライブラリー、自動再生を使用しない。

## HTMLのみの開閉

スマホメニューとお知らせ詳細は `details` / `summary` で開閉する。
キーボードのEnter / Spaceでも操作可能。JavaScriptは不要。

## 下層ページと導線

- トップのお知らせ「もっと見る」→ `news.html`。支給原稿の5件を掲載し、本文を初期表示する。タイトルから開閉できる。
- トップの診療内容「もっと見る」→ `services.html`。導入文と全7項目を掲載し、目次から各項目へ移動できる。
- トップの当院について「詳しく」→ `about.html`。紹介全文、7つの理念・方針、4名のスタッフ紹介を掲載する。
- 下層ページは共通ヘッダー・フッター、パンくずリスト、ページ見出しと写真、トップへ戻るリンクを持つ。
- 下層ページのメニューは3ページ相互とトップへ接続する。アクセスは `index.html#access`、スタッフ紹介は `about.html#staff` に接続する。
- 下層ページのPC表示は写真と文章を左右に、スマホは縦に配置する。共通の色・書体・角丸・背景画像を使用する。
- 全ページのメニューに「ご挨拶」と「診療科目」を設ける。前者はトップの院長挨拶、後者はトップの診療科目一覧（`index.html#departments`）を指す。
- 上部メニューとトップページ本文の両方で、スタッフ紹介をアクセスの前に置く。本文の各セクションは背景色も含めて移動する。

## 地図・連絡先

地図は支給された `map.jpg` を使用する。クリックすると画像自体を新しいタブで開く。
医院・人物・連絡先・住所は架空。電話番号とメールは表示のみで、発信リンク・送信フォームは設けない。

## CSS

`css/style.css` から `assets/css/style.css` を読み込む。メインCSSを一箇所だけ管理する。
画像は `assets/images/` 配下。ファイル名・フォルダー名の大文字小文字を一致させる。
