# デザイン設定

| 項目 | 値 |
| --- | --- |
| 暗色の文字 | `#2e3d37` |
| アクセントのグリーン | `#09d46f` |
| カードの淡いグリーン | `#b5f2d4` |
| 基本の背景 | `#ffffff` |
| フォント | Noto Sans JP、400 / 500 / 700 |
| PCの本文 | 16〜24px、画面幅に合わせて可変 |
| PCの大見出し | 32〜64px、画面幅に合わせて可変 |
| スマホの本文 | 20px |
| スマホの診療内容の本文 | 16px |
| スマホのアクセスの本文 | 18px |
| スマホの大見出し | 48px、小さい画面では40px |
| コンテンツの横幅 | PC：画面の83.333%、最大1600px |

写真は `object-fit: cover` で枠に合わせてトリミングする。
PCの紹介写真は正方形、スマホは横長。背景パターンは支給PNGを使う。
ピクトグラムの透明な余白はCSSの表示窓で切り取り、画像本体を編集せずに表示する。
人物写真は枠内で拡大・位置調整し、添付デザインのトリミングに近づける。
