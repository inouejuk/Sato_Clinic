# 佐藤医院 サンプルサイト

添付のデスクトップ・スマホデザインに合わせた、職業訓練用の架空サイトです。

## 開き方

ZIPを展開し、`satoclinic/index.html` をブラウザーで開いてください。
ページの表示・メニュー・カルーセルはHTML / CSSで動作します。写真のフェードアップにJavaScriptを使用しています。ビルド、npmは不要です。

## フォルダー構成

| パス | 内容 |
| --- | --- |
| `index.html` | トップページ本体 |
| `news.html` | お知らせ一覧・詳細（全5件） |
| `services.html` | 診療内容（全7項目） |
| `about.html` | 当院の診療方針・理念・スタッフ紹介 |
| `css/style.css` | 指定されたCSSの読み込み口 |
| `assets/css/style.css` | メインのCSS。色・文字・配置・レスポンシブ設定 |
| `assets/images/` | 写真・ロゴ・アイコン・背景・地図 |
| `assets/fonts/` | Noto Sans JPとフォントのライセンス |
| `assets/js/script.js` | 写真のフェードアップ処理 |
| `docs/` | 制作要件・仕様・デザイン設定と支給原稿 |
| `AGENTS.md` | 今後の編集用ルール |

`directorySample.png` の `assets/css/` と `assets/images/` に合わせています。
要望に記載された `css/style.css` も用意し、そこからメインCSSを読み込みます。
CSSを変更するときは `assets/css/style.css` を編集してください。

## 表示と操作

- 幅768px以上ではPCレイアウト、767px以下ではスマホレイアウトです。メニューは900px以下で開閉式に切り替わります。
- 901px以上では、画面幅いっぱいの白50％の帯をヒーロー写真に重ね、帯とボタン群だけを画面上部に固定しています。白いカードに載せたロゴはページと一緒にスクロールします。900px以下は従来どおり、追従する開閉式メニューです。三本線を押すとメニューが開きます。
- デスクトップのヒーローは切り欠きのない角丸の長方形です。「地域に根差した医療」は写真の左上に半透明の白背景を添えて表示します。
- 「ご挨拶」はトップの院長挨拶へ、「診療科目」はトップの診療科目一覧（`#departments`）へ移動します。
- お知らせのタイトルを押すと詳細が開きます。
- お知らせ・診療内容の「もっと見る」、当院についての「詳しく」は、それぞれの下層ページへ移動します。
- 下層ページにはパンくずリストとトップへ戻るリンクがあります。診療内容・当院については目次から各項目へ移動できます。
- お知らせページは全5件の本文を表示し、タイトルから詳細を開閉できます。
- スマホ版では、ヒーロー直下の写真3枚と、トップ・当院についてのスタッフ紹介を横にスワイプできます。下の小さな丸からも各写真・スタッフへ移動でき、表示中の丸が緑色になります。
- スマホのスタッフ紹介は、写真・氏名・紹介文を淡いグリーンのカードにまとめ、角丸・枠線・控えめな影と本文の余白で対応関係を明確にしています。原稿は全文を掲載し、横スワイプと丸の位置表示を維持しています。
- カルーセルを選択してキーボードの左右矢印でも操作できます。PC版では写真は3列、スタッフ紹介は縦に表示します。
- フェードアップは768px以上のデスクトップ版だけで有効です。ヒーロー直下の写真・お知らせ写真・ご挨拶写真と、トップの診療内容・スタッフ紹介のカード全体は、表示領域に入るとフェードアップします。カードには淡いグリーンの背景・枠線・影を付け、動きの軽減設定ではカードを初めから表示します。スマホ版では写真とカードをすぐに表示し、カルーセルのスワイプと丸の操作で切り替えます。
- 地図を押すと、支給された地図画像を新しいタブで拡大できます。
- トップ上部の診療表は支給PNGを使用し、768px以上ではヒーロー写真の右下に重ね、767px以下ではヒーロー写真の直下に配置します。読み上げ用の代替テキストも付けています。アクセス欄の診療時間表は、引き続き文字が読めるHTMLの表で表示します。

## 留意事項

- 添付デザインのトップページに加え、同じトーンのお知らせ・診療内容・当院についての3ページを実装しています。予約・送信機能、CMSは含みません。
- 地図はデザインと同じ支給画像です。Googleマップの埋め込みは使用していません。
- Noto Sans JPを同梱して読み込みます。外部への通信なしでも指定書体で表示できます。フォントのライセンスは `assets/fonts/OFL.txt` に同梱しています。
- 支給デザインはPCが288×2048px、スマホが66×2048pxの縮小画像のため、細かな文字は掲載原稿から補っています。
- 掲載原稿の日時・曜日は支給値のままです。実際の診療予定を示すものではありません。
- `noindex, nofollow` と、学習用の架空サイトである断り書きを実装しています。
- カルーセルの丸はCSSのスクロール位置の検出に対応したブラウザーで表示します。Chrome / Edge 140以降では `scroll-target-group`、Safari 26以降ではスクロール連動アニメーションを使用します。両方に未対応のブラウザーでは丸を非表示にし、横スワイプでの閲覧を維持します。対応情報は [Chromeの公式資料](https://developer.chrome.com/release-notes/140#css_scroll-target-group_property)・[Safari 26の公式資料](https://webkit.org/blog/17333/webkit-features-in-safari-26-0/)・[timeline-scopeの互換データ](https://raw.githubusercontent.com/mdn/browser-compat-data/main/css/properties/timeline-scope.json)を参照してください。

## GitHub Pages用

`index.html` が公開元フォルダーの直下になるように、`satoclinic` の中身をリポジトリへ配置してください。
画像・CSSのパスは相対パスです。`assets` と `css` も一緒に配置してください。

## 表示確認

トップと下層3ページを、Chromeの320px / 402px / 768px / 900px / 901px / 1024px / 1440px / 1920pxの画面幅で確認しました。
画像とフォントの読み込み、横にはみ出さないこと、PC・スマホ幅でのメニュー・お知らせの開閉、下層ページへのリンクを確認しています。
カルーセルはChrome 154の320px / 402px / 767pxで、丸の色と全スライドへの移動、写真がフェードせず表示されることを確認しました。402pxではスワイプ・丸のリンク・キーボード操作を確認しています。768px / 1440pxでは写真3列の配置と写真のフェードアップを確認し、PCからスマホ幅へ変更したときの切り替えも確認しました。ページ全体の横はみ出しはありません。
スクロール連動アニメーションの代替処理、丸が非表示になる未対応環境、動きの軽減設定は、Chrome上で条件を切り替えて確認しました。Safariの実機では未検証です。
トップの診療内容・スタッフ紹介のカードは、Chrome 154の768px / 900px / 901px / 1024px / 1440px / 1920pxで、背景・写真・本文が一緒にフェードアップし、枠内に収まることを確認しました。320px / 402px / 767pxでは診療内容のカードの影と、写真・カードのフェードアップが無効で、スタッフのスワイプと丸の操作、画像・メニュー・お知らせ詳細の開閉が動作し、ページ全体の横はみ出しがないことを確認しました。カードの動きの軽減設定と、PCからスマホ幅への切り替えも確認しました。

スマホのスタッフ紹介カードは、Chrome 154の320px / 402px / 767pxで、トップ・当院についての全4名の写真と紹介文が枠内に収まり、丸のリンクと表示位置の色が追従することを確認しました。402pxではタッチのスワイプとキーボード操作を確認しました。全4ページを320px / 402px / 767px / 768px / 1440pxで確認し、画像・メニュー・お知らせの開閉が動作し、ページ全体の横はみ出しがないことを確認しました。PCからスマホ幅への切り替えと、動きの軽減設定でもカードと丸が表示されます。

変更前のデスクトップヘッダーは、Chrome 154の901px / 1024px / 1440px / 1920pxで全4ページを確認しました。白50％の帯の上下の余白が等しく、ボタン群のみが追従し、ロゴはスクロールで画面外へ移動します。画像の読み込み、ボタンの操作領域、ページ内リンク、お知らせの開閉、横はみ出しも確認しました。320px / 402px / 767px / 768px / 900pxでは全4ページのヘッダーの配置・スタイルが変更前後で一致し、402pxでメニュー・お知らせの開閉と画像の読み込みを確認しました。

シンプル化したヒーロー写真は1.92:1の角丸長方形に収まります。追従表示の修正後は、Chrome 154の901px / 1024px / 1440px / 1920pxで全4ページを確認しました。白50％の帯とボタンだけが画面上部に残り、ロゴはスクロールで画面外へ移動します。ロゴとボタンのクリック領域、画像の読み込み、詳細開閉、ページ全体の横はみ出しがないことを確認しています。900px以下の追従ヘッダーとスマホの写真配置は従来どおりです。

トップ上部の診療表は、Chromeの320px / 402px / 767px / 768px / 900px / 901px / 1024px / 1440px / 1920pxで確認しました。PCでは写真の右下、スマホでは写真の直下に表示され、見出しとの重なり・画像の縦横比の崩れ・ページ全体の横はみ出しがないことを確認しました。画像の読み込み、メニューとお知らせ詳細の開閉も確認済みです。PNGの透明な罫線は、CSSの暗色背景で見えるようにしています。
